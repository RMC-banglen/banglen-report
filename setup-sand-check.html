① SQL — Supabase

  1. กด คัดลอก SQL
  2. กด เปิด SQL Editor → วางลงไป → กด Run (รันซ้ำได้ ไม่ซ้อน)
alter table sand_fm_tests add column if not exists w_sample numeric;
alter table sand_fm_tests add column if not exists w_detail jsonb;
alter table sand_silt_spec add column if not exists sieve_tare jsonb;
alter table sand_silt_spec add column if not exists sieve_tare_at timestamptz;

② Apps Script — แจ้งเตือน Telegram แบบรวม

  1. กด คัดลอกโค้ด
  2. เปิดโปรเจกต์ Apps Script → กด Ctrl+F พิมพ์ d.test === 'stone' → จะเจอบรรทัด 943 (ตรงกับภาพสคริปต์ของคุณ)
  3. คลิกที่ ท้ายบรรทัดก่อนหน้า (บรรทัด 942) → กด Enter → กด Ctrl+V วางตรงบรรทัดใหม่นั้น ตามภาพด้านล่าง (ห้ามวางทับทั้งไฟล์ เพราะโทเคน Telegram อยู่ในไฟล์จริง) แล้วกด Save
  4. Deploy → Manage deployments → ไอคอนดินสอ → Version: New version → Deploy
